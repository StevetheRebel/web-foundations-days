About QuickNOtes

QuickNOtes is my note taking tool where I can be able to add, edit and save texts. It is still a simple HTML structure currently.

How to use QuickNOtes

  1. Open the app
  2. Type in the input space
  3. Save the note for later

Features

  • Saved notes can be reviewed later
  • You can edit the notes later
  • You can also delete notes when you don't need them.

Keyboard Shortcuts

Shortcuts Actions
Save Saves the note you typed.
Delete Deletes the note from the list
